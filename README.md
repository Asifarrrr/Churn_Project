# 📊 Customer Churn Prediction

This project focuses on predicting customer churn using Machine Learning and Python.

Customer churn happens when customers stop using a company's products or services. The goal of this project is to analyze customer data, identify patterns, and build a model that can predict whether a customer is likely to leave.

## 🎯 Project Objectives

- Explore and understand the customer dataset.
- Perform data cleaning and preprocessing.
- Analyze different factors that may influence customer churn.
- Train and evaluate Machine Learning classification models.
- Make predictions based on customer information.

## 🛠️ Technologies Used

- **Python** – Main programming language.
- **Pandas** – Data manipulation and analysis.
- **NumPy** – Numerical operations.
- **Matplotlib / Seaborn** – Data visualization.
- **Scikit-learn** – Machine Learning models and evaluation.

## 🔍 Project Workflow

1. **Data Exploration:** Understanding the dataset, its columns, and the relationships between features.
2. **Data Preprocessing:** Handling missing values, preparing categorical features, and getting the data ready for training.
3. **Exploratory Data Analysis (EDA):** Exploring customer behavior and identifying patterns related to churn.
4. **Model Training:** Training classification models to predict customer churn.
5. **Model Evaluation:** Evaluating model performance using appropriate classification metrics.

## 📈 Results

The project aims to build a classification model that can distinguish between customers who are likely to leave and those who are likely to stay.

Model performance is evaluated using classification metrics such as accuracy, precision, recall, and F1-score.
